# Win chance from pro games (research)

Generated by `node scripts/win-chance.ts` from 494 pro games with a full simulation. Not shown in the app yet.

**The model.** At every 30 seconds of a game, the differences between the two players: army value (also as a ratio), workers, hero experience, bases, tier, resources spent, resources lost and food. Each is also multiplied by the game time, so a lead can weigh more or less as the game goes on. A logistic regression with no intercept turns them into a chance to win; the two players' chances always add up to 100%. Each game weighs the same, whatever its length.

**Differences kept:** workers, hero experience, bases, tier, resources lost, food used. The others were dropped because leaving them out made the model no worse on unseen games (the table at the end).

**The test.** Two-fold: fitted on half the games (by game key) and scored on the other half, then the other way round. Every number below is on games the model did not see.

| Score on unseen games | Model | Coin flip |
|---|---|---|
| Log loss (lower is better) | 0.594 | 0.693 |
| Brier score (lower is better) | 0.203 | 0.250 |
